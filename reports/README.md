# reports/

PC'de çalışan scriptlerin çıktıları buraya yazılır.

- `*.txt` – kısa özetler. Repoya girer; GitHub Desktop ile push'la, ben okuyup yorumlarım.
- `samples/*.json` – borsa cevaplarından küçük, herkese açık örnekler (VM testleri için).
- `logs/` – ayrıntılı loglar. Repoya **girmez** (.gitignore).
